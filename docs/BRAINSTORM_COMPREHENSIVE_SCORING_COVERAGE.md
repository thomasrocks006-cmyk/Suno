### PART 3: MISSING SCORE CATEGORIES

**Question**: Should we add new scoring dimensions beyond the current 6(+1)?

**Candidates for New Categories**:

#### 8. **Imagery & Sensory Detail** (0-10)
- **What it measures**: Use of specific, sensory language vs abstract/vague
- **Example**: "Her perfume smelled like summer rain" vs "She smelled nice"
- **Agent assignment**: Songwriter Agent (Lyrical Poet if expanded)
- **Why it matters**: Vivid imagery = stronger emotional connection

#### 9. **Narrative Coherence** (0-10)
- **What it measures**: Story clarity, character consistency, plot progression
- **Different from Thematic Cohesion**: Thematic = conceptual unity, Narrative = story arc
- **Example**: Does verse 1 setup pay off in verse 2/chorus?
- **Agent assignment**: Songwriter Agent (Emotional Architect if expanded)
- **Why it matters**: Storytelling songs need clear progression

#### 10. **Wordplay & Cleverness** (0-10)
- **What it measures**: Puns, double meanings, internal rhymes, wit
- **Different from Lyrical Originality**: Originality = avoiding clichés, Wordplay = linguistic creativity
- **Example**: "I'm a new man, yeah I'm a Newman" (Fresh Prince)
- **Agent assignment**: Songwriter Agent (Lyrical Poet if expanded)
- **Why it matters**: Elevates hip-hop, indie, and witty pop songs

#### 11. **Vocal Delivery Mapping** (0-10)
- **What it measures**: Guidance on WHERE to whisper, belt, use ad-libs, change dynamics
- **Example**: Marking which lines should be sung softly vs powerfully
- **Agent assignment**: Producer Agent (Flow Engineer if expanded)
- **Why it matters**: Lyrics without delivery guidance = incomplete vision

#### 12. **Energy Dynamics** (0-10)
- **What it measures**: Variation in intensity across song (loud/soft, fast/slow)
- **Different from Structure & Pacing**: Pacing = section timing, Energy = intensity variation
- **Example**: Does song build to climax or stay flat?
- **Agent assignment**: Producer Agent (Structural Designer if expanded)
- **Why it matters**: Flat energy = boring song

#### 13. **Contrast & Variety** (0-10)
- **What it measures**: Do verse/chorus/bridge feel distinct?
- **Example**: If chorus sounds too similar to verse = low contrast
- **Agent assignment**: Producer Agent
- **Why it matters**: Repetitive structure = listener disengagement

#### 14. **Cultural Relevance** (0-10)
- **What it measures**: References feel current vs dated, slang usage, trend awareness
- **Example**: Using 2024 slang vs 2015 phrases that sound old
- **Agent assignment**: Commercial Strategist (if added)
- **Why it matters**: Dated references kill commercial potential

#### 15. **Authenticity & Voice** (0-10)
- **What it measures**: Does this sound like AI wrote it vs human experience?
- **Example**: Personal details, specific emotions vs generic "love" themes
- **Agent assignment**: Songwriter Agent (Artist Agent if expanded)
- **Why it matters**: Listeners detect inauthenticity

#### 16. **Risk & Innovation** (0-10)
- **What it measures**: Does song push creative boundaries or play it safe?
- **Example**: Experimental structure, genre-blending, unconventional themes
- **Agent assignment**: Artist Agent (if added)
- **Why it matters**: Safe songs blend in, risky songs stand out

#### 17. **Quotability & Shareability** (0-10)
- **What it measures**: Presence of meme-able, Instagram caption-worthy lines
- **Example**: "I got 99 problems but..." vs unmemorable generic lines
- **Agent assignment**: Commercial Strategist (if added)
- **Why it matters**: Viral moments drive streams

#### 18. **Accessibility vs Depth** (0-10 scale, 5 = perfect balance)
- **What it measures**: Can casual fans AND critics both appreciate it?
- **Example**: Taylor Swift masters this (surface simple, deep subtext)
- **Agent assignment**: A&R Agent (if added)
- **Why it matters**: Best songs work on multiple levels

### PART 10: DECISION FRAMEWORK

**Question**: How do we decide which new categories to add?

**Evaluation Criteria**:
1. **Impact**: Does this dimension significantly affect song quality? (Weight: 3x)
2. **Measurability**: Can we accurately assess it with AI? (Weight: 2x)
3. **Distinctness**: Is this truly unique or overlap with existing categories? (Weight: 2x)
4. **Actionability**: Can users fix issues in this category? (Weight: 2x)
5. **Genre Relevance**: Does this matter across all genres or just some? (Weight: 1x)
6. **Cost**: How expensive is it to compute? (Weight: 1x)

**Scoring Formula**:
```
Priority Score = (Impact × 3) + (Measurability × 2) + (Distinctness × 2) + (Actionability × 2) + (Genre Relevance × 1) - (Cost × 1)
```

**Decision Thresholds**:
- Score > 20: Add as core category
- Score 15-20: Add as optional/advanced category
- Score 10-15: Add as sub-metric within existing category
- Score < 10: Don't add (not valuable enough)
